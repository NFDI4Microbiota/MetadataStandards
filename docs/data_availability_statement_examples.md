# Data Availability Statement examples

A Data Availability Statement should identify where data and metadata are deposited, provide persistent identifiers, describe access conditions, and explain any restrictions.

## Open repository deposition

The raw sequencing data have been deposited in [repository] under accession [ACCESSION]. Associated sample metadata and processed tables are available in [repository] under DOI [DOI]. The analysis code is available at [repository] under [software license].

## Controlled access

The human-associated data cannot be openly released because [specific ethical/legal reason]. Access may be requested through [controlled-access repository / data access committee] under accession [ACCESSION], subject to [conditions].

## Embargoed data

The dataset has been deposited in [repository] under DOI/accession [ID] and is under embargo until [date]. Metadata required for review are available through [reviewer/private link] where permitted.
